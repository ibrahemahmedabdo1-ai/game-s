# قلب الجاذبية: عدّاء الممر

**العنوان:** قلب الجاذبية: عدّاء الممر

**وصف قصير:** اضغط لقلب الجاذبية وتفادَ الأعمدة. ١٠٠ مرحلة ووضع لا نهائي.

**الوصف الكامل:**

تندفع كرتك عبر ممر نيون. اضغط لقلب الجاذبية بين الأرض والسقف، وتفادَ الأعمدة وصِل إلى المخرج.

المميزات
- ١٠٠ مرحلة مع نقاط حفظ ونجوم وأذرع دوّارة ومفاتيح وبوابات
- مهام يومية بمكافآت عملات
- وضع بقاء لا نهائي تزداد سرعته
- تحدٍ يومي
- ست أشكال للكرة قابلة للفتح
- تحكم بلمسة واحدة
- تعمل بدون اتصال، عربي وإنجليزي

تحتوي على إعلانات. الإعلانات المرئية المكافِئة اختيارية دائماً.

**ملاحظات الإصدار (ar):** الإصدار الأول.
