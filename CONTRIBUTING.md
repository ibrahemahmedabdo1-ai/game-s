# Contributing
1. Run `scripts/validate_all.sh` before pushing (analyze + tests).
2. Never commit keystores, `key.properties`, or real AdMob IDs.
3. Never change a game's `APP_ID` after it has shipped.
4. New game: copy an existing app folder, edit `app.properties`, add icons under `store_assets/<game>/icons`, add it to the workflow matrices.
